# Checklist de Revisão de Spec

## Cobertura de requisitos

- [ ] Problema e objetivo estão claros e observáveis.
- [ ] Escopo e não-escopo evitam ambiguidades.
- [ ] Critérios de aceite são mensuráveis e independentes.
- [ ] Casos de erro relevantes foram mapeados.

## Rastreabilidade

- [ ] Todo AC possui tarefa(s) correspondente(s) no plano técnico.
- [ ] Toda tarefa aponta para uma estratégia de teste.
- [ ] Evidências de validação foram registradas por critério.

## Qualidade técnica

- [ ] Requisitos não funcionais foram tratados.
- [ ] Riscos críticos possuem mitigação explícita.
- [ ] Decisões técnicas e trade-offs estão documentados.

## Prontidão para entrega

- [ ] Rollout/fallback/rollback está definido.
- [ ] Não há pendências bloqueantes não documentadas.
- [ ] Resumo final inclui entregue, pendente e risco residual.
